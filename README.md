# The Hollow Crown

An HD-2D action RPG: wake on a strange shore, take up the village's quests, and descend into the
Sunken Abbey beneath the graveyard. Fight for gold and loot, spend it on better gear, go deeper.

## Run it
```
npm install     # first time only
npm run dev     # opens a local server with instant reload
```
Then open `/hd2d.html`. (`/` is the original 2D prototype.)

**Controls:** WASD move · Shift run · Click attack / use item · 1–5 or wheel select ·
Space talk · E backpack · Q quests · T read a Return Scroll · F toggle visual effects

Progress autosaves in the browser (localStorage); "New Game" on the title screen wipes it.

## Build for sharing
```
npm run build   # outputs a ready-to-upload game in dist/
```

## Where things live (`src/hd2d/`)
- `main.js` — game loop, travel between the outskirts and abbey floors, loot, saving.
- `map.js` — the outskirts as a text grid plus house positions, generated by `tools/gen_map.py`
  (edit by hand, or change and re-run the script, which overwrites hand edits).
- `dungeon.js` — random abbey floors: themes, bosses, which enemies live on each floor.
- `world.js` — `Level`: builds and collides against either kind of map.
- `quests.js` — quests, the abbot's journal pages, the intro. `npcs.js` — villagers and dialogue.
- `Enemy.js` — enemy types and bosses. `items.js` — items, magic affixes, uniques, prices.
- `zones.js` — outskirts regions and what spawns there.

## Art
Characters, enemies and gear come from the Himeko Sutori sprite pack, copied into
`public/assets/sprites/`. Characters are stacks of layers (body, outfit, hair, helmet, weapon).
After copying in new gear layers, regenerate inventory icons with:
```
python tools/make_icons.py
```
The original 2D prototype's sprites live in `public/assets/images/`.
